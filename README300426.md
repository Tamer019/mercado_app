# 🛒 Mercado – Supermarkt Preisvergleich

Ein voll funktionsfähiger Web-Scraper + API + Frontend für den Vergleich von Supermarkt-Angeboten (basierend auf Marktguru-API).  
Entwickelt mit FastAPI, PostgreSQL, Vanilla Frontend. Läuft auf Render (Backend) und Netlify (Frontend).

## 🧠 Projektübersicht

- **Scraper** (`scraper/`) ruft Angebote von der Marktguru-API ab und speichert sie in PostgreSQL.
- **FastAPI-Backend** (`api/`) stellt die Daten über `/search`-Endpoint bereit.
- **Frontend** (`frontend/`) zeigt die Ergebnisse an und unterscheidet zwischen aktiven Angeboten und gespeicherten Normalpreisen.
- **Originalpreise** werden in Tabelle `originalpreise` gespeichert (automatisch aus API oder manuell).
- **Testdaten** werden bei API-Start automatisch eingefügt.

## ⚙️ Setup (lokal)

### 1. Repository klonen

```bash
git clone <dein-repo-url>
cd mercado
2. Virtuelle Umgebung

bash
python -m venv venv
source venv/bin/activate        # Linux/Mac
venv\Scripts\activate           # Windows
3. Abhängigkeiten installieren

bash
pip install -r requirements.txt
4. PostgreSQL (lokal)

Datenbank erstellen: CREATE DATABASE mercadodb;
Verbindung in scraper/db_connection.py anpassen (Host, Port, User)
5. Tabellen & Testdaten (lokal)

bash
cd scraper
python db_setup.py
🚀 Lokal starten

Backend

bash
uvicorn api.main:app --reload --port 8000
Frontend (separates Terminal)

bash
cd frontend
python -m http.server 8001
Oder beides zusammen:

bash
python start.py
